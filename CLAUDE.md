# CLAUDE.md

Read `AGENTS.md` first.

This repository uses specification-driven development.

The canonical project documentation is stored in `/docs`.

Before planning, reviewing, or implementing:

- read `docs/PRODUCT.md`
- read `docs/SPEC.md`
- read `docs/ARCHITECTURE.md`
- read `docs/DECISIONS.md`
- read `docs/TASKS.md`

## Working rules

- Do not silently convert assumptions into requirements.
- Keep `PENDING` items pending until a human approves them.
- When reviewing another AI's implementation, compare it against:
  1. `docs/SPEC.md`
  2. `docs/DECISIONS.md`
  3. Figma, once available.
- Report spec deviations separately from optional improvements.
- Do not implement optional improvements unless explicitly requested.
